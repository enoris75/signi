# C-needs-engine — tasks blocked on a construct, or deferred

**None open as of 2026-09-21.** C20, C21 and C22, the last of them, shipped that day: the pronoun
that names its antecedent, the phrase console's diagnostics, and the help overlay's prose. Every
earlier C is in [`done/`](../done/), including the two that were retired by splitting rather than
built (C05, C18).

A file belongs here when the string or gloss needs a grammatical construct the engine cannot render
yet — its **Blocked on** section names it, with a probe showing what comes out today — or when it is
deliberately left on the English literal because no distinguishing phrase can be composed
([C15](../done/C15-ui-literal-by-design.md) collects those). A C task retires either by building the
construct or by splitting into the A and B tasks its pieces turn out to be. See
[the index](../localization-tasks.md#part-c--needs-engine--deferred-c-needs-engine) for the encoding.
