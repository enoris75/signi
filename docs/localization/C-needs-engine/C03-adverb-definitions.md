# C03. Adverb definitions — all 6 adverbs

**Blocked on:** an **adverb (manner/degree) render mode**, plus manner/pace nouns. An adverb's
definition is a manner phrase ("at high speed", "in a good way", "at all times"), which needs the
same predicate/complement machinery as C02 and dimension nouns (SPEED, WAY, TIME) seeded.

## What's needed

- The manner-phrase render (builds on C02's construct).
- Nouns: SPEED, MANNER/WAY, TIME (for FAST/SLOWLY, WELL, ALWAYS/NEVER).

## Blocks

FAST ("at high speed"), SLOWLY ("at low speed"), WELL ("in a good way"), TOGETHER, ALWAYS ("at all
times"), NEVER ("at no time") — all 6.

Lowest priority: 6 concepts, highest per-concept engine cost. Stay on the English literal.
