# A14. BROWN attaches with no linker (`茶色猫`)

**Language:** Japanese

`茶色` is a noun ("brown[ness]"), so attributively it needs `の` — `茶色の猫` — like the other
noun-adjectives (`男性の`, `定冠詞の`). It is the one adjective of 47 that comes out bare.
