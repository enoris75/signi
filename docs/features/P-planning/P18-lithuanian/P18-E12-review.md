# P18-E12. The review — a native Lithuanian speaker signs off the sheet

**Feature:** every string the Lithuanian row renders is confirmed or corrected by a native speaker.
**Shape:** the generated [review-sheet-lt.md](review-sheet-lt.md) (2,307 rows, nouns grouped by
declension class), corrections applied as data edits in `packages/backend/src/concepts/lt/` (or in
`helpers.ts`, where a whole class is wrong) and pins in `packages/engine/test/languages/lt.test.ts`,
rulings recorded in the P18 README.
**Scope:** corpus corrections, helper and engine fixes, suite pins. Phase 4.
**Status:** open. Filed 2026-09-28 with E1–E11. Needs a reviewer; none contacted.

## Why

P18 D12: every form is drafted from model knowledge, most of them generated by class helpers. A wrong
ending in a helper is wrong for a whole class, and only a native reader notices it.

## Rulings owed

- The decisions most likely to be amended: D6 (the 3rd-person pronoun kept), D7 (the subjectless generic
  subject, or *valgoma pelė*), D8 (no definite adjectives), the aspect table §0.3, and the row label
  *Lietuvių kalba* against the bare *Lietuvių* (§3).
- The engine's departures from the plan (README §6).
- The helpers' rules, one class at a time: the *-ias / -jas / -tojas* locatives and vocatives, the *-is*
  adjective neuter (*dideli*), the *-si* ending table (*praustumeisi, prausęsis, prausdamiesi*), the
  future shortening (*bus, įgis, sugrius*), *nėjo* against *neėjo*.
- The column authors' `(verify)` items (grep `(verify)` in `concepts/lt/`); among the word choices:
  REPLACE *atstoti* (it gives *Atstoti žodį* where *Pakeisti žodį* is expected — CHANGE holds *keisti*),
  LEAVE *apleisti*, UNDO *anuliuoti*, REDO *perdaryti*, RESIZE *masteliuoti*, TYPE *rinkti*, PRECEDE
  *pirmauti*, PARENT *gimdytojas*, CAT *katė* as the general word, VALUE *vertė*, TAB *skirtukas*, the
  invented adverbial names (*priemonės, palydos, … aplinkybė*) and grammar terms, NO_LONGER *jau ne*
  (*nebe-* would need an engine key).
